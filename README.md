# 九九アドベンチャー（ククと九九の島）ろくおんボイス版

子ども向け九九学習アプリ **の、自然な録音音声バージョン** です。
九九の読み上げを端末の音声合成ではなく、あらかじめ録音した音声ファイル（`audio` フォルダー）で再生します。どの端末でも同じ声で聞こえます。

アプリ本体は v1.1（ひらがな化・具体物イラスト・小画面対応）と同内容で、音声まわりだけが違います。

## このバージョンのポイント

- 読み上げは全81問分（1問ごとに「出題」と「答えの読み上げ」を1ファイルに収録）＋あいさつ等の **音声86ファイル** を録音音声で再生（端末に日本語音声が入っていなくても声が出ます）
- 「おぼえる」では **上がり（1→9）／戻り九九＝さかさま（9→1）／バラバラ** の3通りで暗唱が聞けます。読んでいる行が自動スクロールして光ります
- 万一音声ファイルが見つからない場合は、端末の音声合成に自動で切り替わる保険付きです

## GitHub Pages で公開する手順

新しいリポジトリ（例：`kuku-adventure-voice`、Public）を作ってください。今の軽い版とは別のリポジトリにするのがおすすめです。

1. ZIPを展開する
2. リポジトリ画面で **Add file → Upload files** を開く
3. 展開した中身（`index.html`、`README.md`、**`audio` フォルダーごと**）をドラッグ＆ドロップして Commit
   - ファイル数は全部で88個（GitHubの1回100個までの制限内）です。フォルダーごとドラッグできない場合は、先に `index.html` と `README.md` を上げ、次に `audio` フォルダーを開いた画面から中身86個を上げる、の2回に分けても大丈夫です
4. **Settings → Pages** で **Deploy from a branch / main / (root)** を選んで Save
5. 数分待つと公開URLが表示されます： `https://<ユーザー名>.github.io/kuku-adventure-voice/`

**使う方は、URLを開くだけです。** 音声フォルダーを別にダウンロードする必要はありません（GitHub Pages がサイトの一部として配信します）。

## ローカルで使う場合の注意

ZIPを展開して `index.html` を直接開く場合は、**`index.html` と `audio` フォルダーを必ず同じ場所に置いてください**。`index.html` だけを移動すると声が出なくなります（その場合は端末の音声合成に切り替わります）。

## 使い方メモ

- 初回はプロフィールのタマゴをタップして「クク」を孵化させます
- 音声入力（🎤）は従来どおりブラウザ依存です（非対応環境では数字タップのみ）
- 進捗データは各端末のブラウザ内に保存されます。軽い版とボイス版でURLが違う場合、進捗は別々に保存されます
